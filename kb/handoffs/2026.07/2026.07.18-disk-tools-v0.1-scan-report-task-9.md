## Completed

- `cli/src/render/skipped.rs`: `render_skipped(&[SkippedEntry], verbose: bool) -> Option<String>` — a pure formatter. `None` when nothing was skipped; otherwise a header (`N entr{y,ies} skipped:`), one `  <path> (<reason>)` line per skip capped at `PREVIEW = 10` unless `verbose`, then a `  … and M more (use --verbose to list all)` tail. `reason()` labels the three `SkipReason` variants.

- `cli/Cargo.toml`: `indicatif = "0.17"`.

## Decisions Made During Implementation

- **Summary always to stderr**, in tree mode too — not just under `--json`. The spec frames the stderr rule around JSON purity, but sending the summary to stderr uniformly is simpler and still shows it on a terminal; it only matters when stdout is piped, where keeping it out is exactly right.
- **`render_skipped`, not `format_skipped`** — renamed for consistency with the `render/` module's `render_tree`/`render_json` (a conventions-review finding). All three return a `String` for the caller to print.
- **Spinner tty-gating is indicatif's job** — `ProgressDrawTarget::stderr()` hides itself when stderr isn't a tty, so a piped run prints no spinner and no control bytes; no explicit `is_terminal` check needed (verified against indicatif source and by pty capture).
- **AC1 has no automated test** — the spinner's visibility needs a pty; covered by construction + ac-verifier's manual pty capture, matching how Task 7's tty width fallback was handled.
- **JSON-encode error skips the summary** — on the `--json` serialize-error path `main` returns `ExitCode::FAILURE` before printing the summary. Acceptable (nothing goes to stdout either); noted.

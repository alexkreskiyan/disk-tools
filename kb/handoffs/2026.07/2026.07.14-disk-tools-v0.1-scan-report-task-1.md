## Decisions Made During Implementation

- **No `pub fn scan()` yet.** It would be a `todo!()` with nothing behind it; Tasks 3–5 build it for real.
- **No constructors on the model** — spec AC #5 asks for field shape. They arrive when Task 3's walk needs them.
- **Core has zero dependencies.** `rayon`/`filesize` land in Tasks 2–3. An empty dep list makes it structurally impossible for the scaffold to smuggle in scan logic.
- **`cli/src/main.rs` touches `ScanOptions::default()`** rather than being empty — otherwise AC #1 would pass on two crates that merely compile side by side without the dependency ever resolving.
- **justfile follows `~/Projects/my/car-finder/justfile`** (same shape of project) — `set shell`, private `default → --list`, section banners, gate named `verify`. Its `cargo +nightly fmt` was **not** copied: that pin exists for unstable rustfmt features this project doesn't use.

## For Next Task

Task 2 is **Sizing — allocated + apparent** (`core/src/size.rs`), depends only on this task.

- **Add deps to `core/Cargo.toml`:** `filesize` (empty `[dependencies]` is waiting for it) and `tempfile` under `[dev-dependencies]` for fixture files.
- **The `filesize` API to use** is `file_real_size_fast(path, &metadata)` — it takes metadata you already have, avoiding a second `stat`. Spec §8.2.1.
- **Don't call `metadata()` to decide file-vs-dir** — `DirEntry::file_type()` is free (it comes from `readdir`). The single metadata call happens once per real file, where size is needed anyway. This is the spec's main performance lever; it's easy to lose by accident.
- **The identity key for hardlink dedup does *not* belong on `ScanNode`.** The bugs reviewer specifically checked this: per §8.2.2/§8.2.3 the key `(st_dev, st_ino)` / `(volume_serial_number, file_index)` lives on the *raw walk entry* — an intermediate type Task 3 introduces — and is consumed by Task 4's dedup pass. By aggregation time (Task 5) bytes are already attributed, so `ScanNode` never needs it. Don't "fix" its absence.
- **Testing gotchas:** platform-gate fixtures with `#[cfg(unix)]` (sparse/hardlink/permission); Windows symlink tests are deliberately skipped to keep CI green without Developer Mode. Tests needing a real mount point are `#[ignore]`.
- **`mutants.out/` is now gitignored** — the verifier's `cargo mutants` runs won't dirty the tree.
- **Verify with `just verify`** (fmt-check + lint + test), not raw cargo.

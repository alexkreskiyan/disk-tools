## Decisions Made During Implementation

- **`Host` is a trait so restoration is testable.** CI has no terminal, and the
  half that breaks echo is raw mode. A recording `Host` lets a test assert the
  exact restore *sequence* and that it happens exactly once.
- **The global "inside" flag belongs to `Crossterm`, not to `Screen`.** My first
  version had `Screen` set it — which would have let one test's state leak into
  another's, since tests run in parallel threads of one process. Caught while
  writing, not by a failure.
- **`catch_unwind`, not an assertion inside a `Drop`.** Asserting during unwind
  panics while panicking, which aborts and takes the whole test binary rather
  than failing one test.
- **`ratatui::crossterm` re-exports the event API**, verified with a throwaway
  crate before committing to it — so there is no separate `crossterm`
  dependency, and no chance of two incompatible copies.
- **The cursor is restored by us, not only by `ratatui`.** The pty trace showed
  `ratatui` hides the cursor on its first draw and shows it on a clean exit — but
  that is a terminal-wide setting on most emulators, so a **panic** would have
  ended with an invisible cursor. `show_cursor` is now part of every restore
  path. This was found by reading the trace, not by any test.

## Deviations from Spec

- **One unrelated fix.** Raising the MSRV unlocked clippy's MSRV-gated lints:
  let chains are stable at 1.88, so `collapsible_if` began firing on
  `core/src/tree.rs:147`, which had passed for three versions. Collapsed.

## For Next Task

**Task 2 is listing, navigation and sorting.** `cli/src/ui/mod.rs::draw` is the
one place that paints, and it currently ignores everything but the path.

**Gotchas discovered:**

- **`script -q /dev/null` gives a pty with no size**, so `ratatui` renders into a
  zero-area frame and draws nothing. The escape trace is still exact, which makes
  it a good check for *lifecycle* and a useless one for *layout*. Layout has to
  be checked by hand.
- Raising the MSRV can break `just verify` through clippy alone, with no code
  change. Expect more of these if it moves again.
- The panic hook chains to the previous hook rather than replacing it, so test
  harness reporting and backtraces still work.
- `Screen::leave` is called explicitly at the end of `run` **and** by `Drop`. The
  first reports a failure to restore; the second catches every other path. The
  idempotence that makes this safe is tested.

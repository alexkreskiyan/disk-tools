## Decisions Made During Implementation

- **The memory limitation was wrong and is now split.** It read "the whole tree
  is held in memory — the planned interactive TUI needs the full tree". The TUI
  that shipped does the opposite, so the row now says what `scan` costs and what
  the browser costs instead.
- **Two new limitations rather than none.** The browser edits a file the user
  may also be editing, and row colours do not consult `requires-clean-repo`.
  Both are real and neither is a bug; the place for them is the table people
  read before trusting the tool.

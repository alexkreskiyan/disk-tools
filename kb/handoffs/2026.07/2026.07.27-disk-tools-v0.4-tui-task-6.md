## Decisions Made During Implementation

- **Edited, not regenerated.** Serialising the parsed form would discard the
  comments that make the file worth having.
- **The decor is lifted from the old value onto the new one.** A trailing
  comment belongs to the value, not the key, so a plain assignment carries it
  off — precisely what this module exists not to do.
- **An absent `[[rules]]` writes the built-ins out too**, and the browser says
  so. `rules = []` is the opposite statement and is left alone.
- **Defaulted keys are removed**; `tier` is always written, because it decides
  whether `--apply` takes something without asking.
- **Atomic write.** A crash part-way leaves a config every verb refuses.
- **The file first, the screen second.**

**Gotchas discovered:**

- `rules = []` is an **inline array**, and `as_array_of_tables_mut` returns
  `None` for it. Same statement as `[[rules]]` with no entries, different
  spelling; it has to be converted before a table can be appended.
- `toml_edit` 0.25 is a second TOML implementation beside `toml` 1.x. They are
  the same family and share a spec version, but the CLI now depends on both.
